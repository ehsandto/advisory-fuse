# Mechanism comparison

| Earlier pattern | AdvisoryFuse |
|---|---|
| Owner proposes graph mutations | Immutable artifact and impact policy; permissionless observations |
| Version/head update | Trip latch and hysteretic recovery with wall-clock freshness |
| Stored-state deterministic graph validation | Independent HTTP acquisition and semantic impact classification |
| Decision certificate, one-time consumption | Reusable root-bound read gate; no mint, certificate or consumption |
| Source-delta dispatch queue | No queued work, worker assignment, lease, priority or acknowledgement |
| Caller outcome or agent summary | Full fetched upstream manifest and official advisory prose |

The reusable value is safety interlocking and anti-flap recovery. Merely copying this
mechanism into another domain would not justify another separate submission.
